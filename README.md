# 392 班随机点名系统

一个美观实用的课堂随机点名系统，支持多种点名模式和公平加权算法。

## 功能特性

### 🎯 核心功能
- **随机点名**：多种点名模式，支持单人或多人抽取
- **公平加权**：基于历史点名记录智能调整被抽中概率
- **逆向概率**：未被抽中的学生拥有更高的被抽中机会
- **成绩关联**：可导入成绩数据，为学生分配排名

### 📊 数据统计
- 实时显示已点名学生数量、总人数、抽签次数等统计信息
- 进度条可视化展示点名进度
- 完整的历史记录，支持查看每次点名的详细信息

### 🎨 界面特色
- 原神风格引用展示
- 多种特殊学生徽章样式（金色、蓝色、绿色、云朵形状等）
- 精美的动画效果（彩带庆祝动画）
- 响尾蛇动画效果

### 🕐 课程表
- 实时显示当前课程信息
- 课程节次倒计时
- 显示下一节课信息

### 🔧 附加功能
- 学生管理：可通过弹窗选择/取消选择学生
- 背景切换：支持更换界面背景
- 历史撤回：支持撤销最近一次点名记录
- 数据持久化：自动保存点名历史

## 使用方法

### 基本使用
1. 在输入框中输入要抽取的学生数量
2. 点击「开始抽签」按钮进行随机抽取
3. 抽取结果会显示在主界面，并自动记录到历史

### 切换模式
- 点击模式切换按钮可在「普通模式」和「加权模式」之间切换
- 加权模式下，被抽中次数少的学生有更高的概率被抽中

### 学生管理
1. 点击侧边栏的学生列表按钮打开学生管理弹窗
2. 在弹窗中可以勾选/取消勾选学生
3. 支持全选/取消全选
4. 点击「确认」保存选择

## 技术栈

- **前端框架**：原生 HTML/CSS/JavaScript
- **图标库**：Font Awesome
- **存储**：LocalStorage
- **算法**：加权随机抽取、逆向概率分布

## 依赖
